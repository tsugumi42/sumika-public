# 界面风格选择

主人在风格挑选页（（私有链接） ，数据在页面数据库 `picks/owner`）里选中的项目。

**这些是默认值，不是唯一方案。** 挑选页上的选项（字体、冷暖、色系与角色色、圆角、疏密、emoji、图标、头像、材质、玻璃浓度、背景、动效、选区、光标等）全部保留，正式版做成"外观设置"让人自己调。配色尤其如此：主人没有专门挑过冷暖色系，表里只是当前的默认。改了默认就更新这一页。

记录时间：2026-10-13（数据版本 109）

| 项目 | 选择 | 说明 |
|---|---|---|
| 中文字体 | 文渊圆体 | 原名文源圆体，2026-07 v1.000 改名；同系列有黑体、宋体 |
| 英文和数字 | 跟中文一样 | 也用文渊圆体 |
| 代码字体 | Maple Mono | 行内代码用 500 字重、0.94em |
| 底色冷暖 | 偏冷 | OKLCH 色相 250 |
| 角色色色系 | 冷色 | A：青 `oklch(0.75 0.1 195)`；B：天青 `oklch(0.71 0.11 232)` |
| 圆角 | 很大（按钮 20px） | 往外每层加内边距，保证同心 |
| 圆角形状 | 超椭圆 | `corner-shape: squircle`，不支持时退回普通圆角 |
| 疏密 | 标准 | 间距单位 8px |
| emoji | Noto Color Emoji（默认，ADR-151）/ Twemoji | Noto：Google 官方 COLRv1 字体（`scripts/fetch-fonts.ts` 按标签下载到 `web/public/fonts`，OFL）。Twemoji：jdecked/twemoji 社区版（setup 时 `scripts/fetch-twemoji.ts` 从它的 GitHub 标签下载到 `web/public/twemoji`，现在钉 v17.0.3，ADR-150）。图形是 **CC-BY 4.0**，关于页要署名；Fluent 扁平还没接 |
| 图标 | MingCute，线条 | 选中项用实心版 |
| 文件类型图标 | Catppuccin Icons（2026-10-14 定） | 粉彩、圆润，最接近整体风格；可选 Material Icon Theme、Symbols、vscode-icons。用 `@iconify-json/catppuccin`，MIT 许可（10-14 已核对）；Iconify 里只有 Macchiato（深色）配色，浅色底上发灰，所以生成时把颜色换成名字，浅色模式填 Latte、深色填 Macchiato |
| 头像 | 圆角方形 | 正圆、Live Orb 可选（10-14 已做进组件库，只影响角色头像）；Orb 的形状和表情继续打磨 |
| 层级 | 淡淡的投影 | 深色模式靠更亮的底色 + 顶边高光 |
| 面板材质 | 液态玻璃 | 磨砂、实色可选；玻璃浓度"标准" |
| 聊天背景 | 柔和图案 | 角色色色晕 + 细点；纯色、图片可选（图片只放内存不保存，模糊 0/12/24/48，默认 24px，能从图里取角色主题色） |
| 动效 | 平滑弹簧 | 默认不回弹；时长和曲线见 Notion「界面动效与层级」 |
| 选中文字 | 圆角色块 | 只取文字矩形、按行合并成一整片 SVG 路径 |
| 输入光标 | 平滑光标（默认，未改） | |
| 侧栏选中 | 待定 | 滑动指示器的样子还要重做 |

未定和待优化：

- 侧栏选中块的样子与颜色；侧栏不应比聊天区更亮更显眼。
- 整体配色算法：每个主题色生成一组明度阶梯（类似 Radix 的 12 阶），组件按用途取阶梯，叠加后的最终颜色要检查对比度。
- Live Orb 的形状、表情和动作。
