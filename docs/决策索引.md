# ADR 现行索引

这是 [决策记录.md](决策记录.md) 的登记层：每条 ADR 一行，写明它现在算不算数、现在还要守什么。以后查“某个决定现在还管不管用”先看这里；ADR 全文只当“为什么这样定”的出处。具体规矩以现行文档（AGENTS.md、LESSONS.md、规格、参考页）为准，ADR 只记来由。

状态只有四种：

- `现行`：没被后来的 ADR 改过，照办。
- `部分修正：被 ADR-N 改了哪一点`：整体还在，改动处以 N 为准；“现在要守的一句”写仍然生效的部分。
- `被 ADR-N 取代`：整条作废，看 N。
- `过时：原因`：没有取代者，但前提已经没了（实现冻结、一次性事项已做完等）。

新增 ADR 时同一个提交在表末加一行；ADR 改动或取代旧 ADR 时同一个提交改被动方那行的状态。判断依据是 2026-11-12 对 ADR-001 到 ADR-356 逐条盘点的结论；当天下午 ADR-359 把后台拉回 Go、界面留在 mygo，按它重判过一遍（原先按“实现落在网页”判的 Go、mygo 类条目）。界面类条目的“现行”指设计结论，实现落在 mygo；与需求登记 R-185～R-196 冲突的以登记为准。
