# 规格：提示词预设（风格、场合）和"每个对话用哪一套"

> 状态（2026-11-16 整理）：Go 读取路径已合 main（`native/internal/prompts` 的 presets/selection）；设置页的提示词页和只读整篇未做。
> 2026-10-21 状态：按 ADR-133 第 6 条做（主人当面拍板的要求在 ADR-133 的依据里）。参考过：MaiBot 的提示词管理页（调研结果写在[待办](待办.md)"提示词与预设的编辑界面"那条里）、[规格-语言 3.8](规格-语言.md)、ADR-106（开口许可）、ADR-121（末尾提醒，**这次不动它的位置**）。

## 1. 三类东西

| 类 | 是什么 | 在哪改 |
|---|---|---|
| 身份 | 角色卡（`character.md`） | 已有（ADR-133 第 3 条） |
| 风格 | 说话的用词、露骨程度这类，一个多行文本 | 本规格新做 |
| 场合 | 本地 / QQ × 私聊 / 群聊各一段（`scene-home`、`scene-home-group`、`scene-private`、`scene-group` 四份现有提示词） | 内置四份已能改；本规格加"复制成自己的场合预设"和选用 |

一个预设 = 名字 + 一行说明 + 一个多行文本（主人 2026-10-21："一个预设就一个多行输入框"）。**不接任何考试、不加任何新门禁**（风险交给用户，主人："直接交给用户来控制风险就足够了"），只保证开口许可的指纹算对（第 5 节）。

## 2. 内置和自定义

- 内置风格：`全年龄向`、`成人向`，**出厂文本都是空的**（主人："成人向默认空着给用户自己填，我们不内置"）。**出厂的永远原样留着；正文可以直接改，改的存成用户版（`presets/builtin/style/<id>.md`），出厂版是历史里最早的一版，随时能换回**（ADR-136；主人原话："原本内置的默认内容是始终有原样留存，修改过的新内容不覆盖默认内容，可恢复"）。名字和说明不能改、不能删；也能"复制为新预设"另写一份。没选风格时用的是"全年龄向"，它被改过就用改过的。
- 内置场合：上面四份 `scene-*`，沿用现有的出厂 / 用户版 / 历史机制，不变。
- 自定义预设：存 `config/prompts/presets/<类>/<id>.md`（正文原样，不带任何包装，保存下来的字节 = 编辑框里的字节），名字、说明、创建时间存 `config/prompts/presets/index.json`。**id 由程序生成**（`u` + 时间戳 + 随机几位，只含小写字母和数字），不拿名字当文件名。同名允许（界面上提醒一下）。
- 自定义预设的每次保存先把旧版存进 `config/prompts/presets/history/<类>/<id>/<时间>.md`，可换回 / 复制 / 删除，和提示词一样。
- 删除：被任何地方选着的预设**不能删**，提示"被 N 处选着：……，先改选再删"。删除时正文和历史一起进 `config/prompts/presets/trash/`（不直接抹掉）。

## 3. 选哪套

存 `config/prompts/selection.json`：

```
{ "defaults":      { "<平台>:<private|group>": { "style": "<id>", "scene": "<id>" } },
  "conversations": { "<会话>": { "style": "<id>", "scene": "<id>" } } }
```

- 平台键：本地是 `local`，别的用渠道名（现在只有 `qq`）；平台列表只写在 `preset-store.ts` 的 `PLATFORMS` 一处（没有渠道注册表可取），加新渠道时在那里加一行，界面上的表跟着多一行。
- 没写 = 内置：风格是"全年龄向"（空），场合是该平台×私聊/群聊对应的那份 `scene-*`。
- 解析顺序：这个会话单独选的 → 这个平台×私聊/群聊的默认 → 内置。风格和场合各自解析。
- 每次拼提示词现读文件（改了不用重启，和提示词一样）。

（**ADR-307 加**：成人向风格另有一层会话名单——`mode: whitelist | blacklist` 加会话列表，可整类写可单个会话；默认白名单只有主人私聊。名单外的会话选了成人向也按全年龄向拼。还没实现。）

## 4. 拼在哪

`router.ts` 的两处 `sections()`（群聊一轮 `groupTurn`、私聊和主窗口 `reply`）：

1. 场合段：解析出来的场合预设的文本（内置就是原来的 `renderPrompt(scene-*)`；自定义的同样替换 `{{变量}}`）。
2. **风格段**：紧跟在场合段后面，`id: style`，`source: 预设：<名字>`；文本空就不出现（`joinSections` 本来就滤掉空段）。
3. 其余（extraPrompts、platformPrompt）照旧在后面。

这些都在**固定前缀**里：同一个会话内每轮不变，所以不碰缓存规则（规格-语言 3.2 "每轮变的只追加在尾巴"）；会话换了预设那一轮缓存会断一次，是预期的。

## 5. 开口许可的指纹（ADR-106）

注入测试结果加一项 `presetHash`：测试时这个会话（或测试脚本指定的会话）解析出的"风格文本 + 自定义场合文本"的哈希；**没有风格文本、也没换成自定义场合时记空串**，所以没用预设的老设置、老测试结果仍然有效。`speakCheck` 多收一个会话，算出现在这个群的 `presetHash`，和最近 3 次测试记的比：不同就"这个群选的风格 / 场合预设和测试时不一样，要重跑"。测试脚本加 `--conversation <会话>`：按那个会话的选法跑。内置场合的文本已经在 `promptHash` 里，不重复算。

## 6. 界面（设置 · 提示词，在 ADR-133 第一步的页上改）

- 左边列表是树：分类 → 项；**场合**这一类下面按平台再分一层（本地（主窗口）、QQ、自己的场合预设），是什么平台就叫什么、不写"平台：QQ"，平台那一层里的项叫私聊 / 群聊 / 平台特有的说明 / 群聊每轮末尾的提醒，每一层各自折叠（2026-10-21 主人要求）；**每类能折叠**（记在浏览器里，`persist`）；项比分类标题缩进一级；自定义预设排在内置后面；每项显示标题 + 一行说明；"排序"：默认 / 按名字 / 最近改过（每类各记一个）。
- **版本和离开前询问（2026-10-21 主人定）**：提示词本身可以改，改了保存就是一份新的，原本（出厂的）作为历史里最早的一版（最后一行"出厂的（最早的一版）"，能换回、能复制，不能删；不再有单独的"恢复出厂"按钮）。改了没保存就点别的项（或"用哪一套"），弹出"保存 / 舍弃修改 / 取消"：保存了再去、舍弃了去、取消留在原处；点弹窗外面、按 Esc 等于取消，回到编辑界面。
- 角色卡开头的 `<!-- -->` 注释（改动记录、待定项，写给人看，拼提示词时 `persona.ts` 会去掉、不给模型看，`docs/角色卡结构.md`）在编辑器里淡显、斜体，一眼能和正文分开。
- 右边：标题和说明（自定义的可改）、编辑器、保存 / 放弃 / 复制为新预设 / 删除（自定义）；内置的（提示词、内置风格）出厂版是历史最后一行，"换成这版"= 换回出厂（ADR-134、136）、历史版本。内置风格也能改，名字和说明不能改、不能删。
- 编辑器里出现的 `{{变量}}` 做成可点的小标签，**点一下复制**（说明这个变量是什么）。
- 编辑框用等宽字体（`--font-mono`）；**所见即所得**选 Obsidian 式的"源码里直接渲染"（标题放大、粗体加粗、列表缩进、代码块着色；光标不在的那一行把 `#`、`**` 标记淡化），不选 Typora 式的完全隐藏标记——因为 `{{变量}}` 和换行、空格必须原样可见，保存的字节必须等于原文（验收第 1 条）。库：CodeMirror 6 + `@codemirror/lang-markdown`。
- 新增"用哪一套"：一张表，行是"平台 × 私聊 / 群聊"，列是"风格""场合"，每格一个下拉；下面"单独设置的会话"列表（会话名 + 两个下拉 + 去掉），要加就从已知会话里选。

## 7. 验收

1. 编辑器往返：把 `prompts/core.md`、`scene-group.md`、角色卡各粘进去不改、保存，字节和原文件完全一样（含行尾空格、`{{`、CRLF 换成 LF 之外的一切）。写成测试；不过的编辑器库直接淘汰。
2. 预设存储：新建 / 改 / 历史 / 换回 / 复制 / 删除（被选着不能删）各一个测试；id 只能是程序生成的，传 `../x` 报错。
3. 拼装：同一个会话选风格前后，`sections()` 只多一段；空风格不出现；解析顺序（会话 > 默认 > 内置）三种各一个测试。
4. 指纹：换了风格、换了自定义场合、什么都没换，`speakCheck` 的结果各一个测试；改坏检查：去掉 `presetHash` 比较 → 换了风格测试变红。
5. 界面：`check-prompts-page` 盖住折叠、排序、新建预设、点变量复制、选用；按 `docs/设计自查.md` 过一遍；十个角色 / 上百个预设下列表元素数量量出来。

## 8. 不做

- 不在预设里放"考试"、不拦截保存。
- 不动末尾提醒的位置（待办"末尾提醒放哪儿"另做对比）。
- 预设不跨机器同步（跟数据目录备份走）。
