# 界面清单

> 2026-10-13 起。列出所有窗口、弹出层和状态，避免漏画。结构见 [信息架构.md](信息架构.md)。
>
> 处理方式：
> - **线框**：结构是我们自己的，要画线框图；
> - **结构样张**：标准浮层，但里面放什么、什么时候出现是我们定的，画一次结构；视觉样式到组件库阶段再做；
> - **列出**：只在这里记下要有，等做到时再画。
>
> 线框图：（私有链接）
>
> 分工：**线框和结构样张**回答"放什么、在哪、什么时候出现"；**组件库**回答"长什么样"（颜色、圆角、阴影、动效）。
