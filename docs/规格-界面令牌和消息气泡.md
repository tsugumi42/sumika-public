## 四、消息气泡族

结构（GROK）：一条消息 = 可选的发送人行 + 气泡 + 可选的悬停操作。正文 Text 号、行高 1.6，段距 = 一个正文字号（GROK `--paragraph-margin:1em`）。

| 内边距 | 竖 s2 − 0.5（约 8）、横 = 竖 + 半个行距（约 12.8，字形到四边等距）；竖向和引用块到气泡边的距离相等 | BUN chat.css:113、132-137（原来写的"横 1.6g 约 13.7"和代码不符，审查 D6 改成代码的公式） |

## 五、设置页（实时）

外观一组四个滑块（字号、圆角、疏密、底色）+ 壁纸开关 + 玻璃开关，拖动时整窗实时重算令牌；旁边放一个小预览（两条她的、两条你的、一条失败）。数值写进工作台状态，不进真实配置。

## 六、质感

- 壁纸（BUN chat.css:46-51）：聊天区画 20 px 格、1 px 点（正文色 9%，羽化到 1.6 px）+ 三团角色色光晕（26% @ 70%/18% 大小 60%×55%，18% @ 95%/85% 55%×60%，14% @ 5%/90% 45%×50%），用 Canvas 画一次缓存，尺寸变了才重画。光晕在椭圆半径的 72% 处淡到透明（Bun 的 transparent 72%，审查 B9）。深浅两种模式光晕浓度一样，照 Bun（原来深色减半是我定的，主人 11-06 看了对比图同意照 Bun）。
- 玻璃：标题栏和输入框用 mygo `plugins/glass`（Regular）；关玻璃或系统降低透明度时用实色 n1。
- 阴影 sh-1：`0 0.5 1` n12 10% + `0 1 3` n12 6%（BUN tokens.css:245）。

## 七、禁止的偷懒

- 组件里写死颜色、间距、圆角数字（全部从令牌取）。
- 几何检查里给某个组件加例外或改阈值。
- 失败、发送中写成一行说明文字。
- 用 `ui.Color.Mix` 混色。
- 自己的消息显示名字或头像。

## 八、已知的坑

- mygo 的 Radius 只认 1 个或 4 个值（MYGO element.go Radius）；逐角半径按左上、右上、右下、左下的顺序。
- Windows 上没有超椭圆（MYGO paint.go:56），先用圆弧。
- 文渊圆体 46 MB：只在启动时读一次文件，不进二进制。
- Tester 是软件渲染，像素只能证明布局，不能代替真窗口截图。

## 九、验收

1. `chatui` 单元测试：令牌在四个设置的边界值（最小、默认、最大）下都满足：内层圆角 ≥ 4、相贴角 ≤ 气泡圆角、对比度（正文、名字、失败角标）≥ 4.5。
2. 气泡几何：Tester 量单条、两条合组、三条合组（自己 / 别人 × 私聊 / 群）× 单行 / 多行，每个气泡四角半径、组内 / 组间间距、引用块四边距离、失败角标贴底（角标底边 = 气泡底边）。改坏检查：相贴角写回大角、失败角标居中、引用块离边不等，各红一次。
3. 设置实时：拖滑块后同一帧内气泡圆角和字号变了（Tester 读 Bounds）。
4. 工作台真窗口：浅深 × 有无壁纸 × 私聊 / 群聊，截消息区组件图给主人看；`go tool mygo vet`、帧统计（万条历史流式 30 秒 p95 ≤ 16.7 ms，空闲 0 帧）。
5. 多代理工作流把每个状态截图和参考并排对照，挑漏铺的规矩。
