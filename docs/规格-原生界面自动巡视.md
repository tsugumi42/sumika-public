## 目标和任务卡

用户目标：AI 能巡视真实 mygo 窗口，以截图、可读树和机器检查发现布局问题。入口为 native/cmd/ui-tour；信息架构为状态清单 → 每状态 PNG/JSON → index.html 和 report.json。配置只属于这次巡视进程，主题改动只留在演示窗口内。既有 MewTypeUI / Telegram 布局、token 不改；本次不修现有布局或 mygo vet 诊断，不操作正式实例、QQ 或任何真实聊天数据。

我定的：Go 标准库 net.Dial("unix") 原样消费官方协议。协议没有 resize，宽/窄、深/浅各启动一个自己的 -demo e2e 子进程，不改系统缩放；不通过 sumika-ctl 触达现有实例。e2e 单实例身份按 socket 隔离，控制管道也隔离。socket 必须放当前用户独占的短路径（Windows AF_UNIX 路径长度受限）；截图和报告可以另放较长输出路径。

主窗口客户区 2048×1030 DIP，要求实测缩放 1.25；窄窗 480×720 DIP。深浅各走会话列表、本地私聊、本地群聊、QQ 私聊、QQ 群聊图文和撤回、三个右侧页、十个演示设置页及其可滚动末尾、搜索空状态、运行和记忆页。通过真实控件操作路由，检查预期标签出现才采集；不点发送、接收、清空、保存后台配置。演示数据使用既有 mock，QQ 群尾部补固定长文、静态图、撤回样本以避免随机种子碰巧未覆盖。

## 数据和检查边界

| 形状 / 输入 | e2e 启动 | ui-tour | go-verify |
|---|---|---|---|
| 普通构建，无 socket | 不导入 automation | 不适用 | 不适用 |
| e2e + -demo + 独立 socket | 只接 mock；隔离实例及控制管道 | 自己启动并只控制该 PID | 不适用 |
| 正式模式 + socket | 拒绝本次巡视启动 | 只以 -demo 启动 | 不适用 |
| 缺路径、socket 太长、连接失败、idle 超时 | 官方错误保留 | 返回非零，保留已有产物 | 不适用 |
| 缺元素 / 同名多个 / offscreen | 不适用 | 不盲点，报状态和匹配信息 | 不适用 |
| 主题缺省 / light / night / 其他 | 仅 socket + -demo 生效，缺省沿用演示默认；非法值创建窗口前返回 2 | 每个子进程传 light 或 night，不依赖窄窗中可能已越界的主题控件 | 不适用 |
| 本地私聊 / 本地群聊 / QQ 私聊 / QQ 群 | 全是 mock，无后台连接 | 只导航和截图，四种都走 | 不适用 |
| 仅内部 Go 包或根包测试文件 | 不适用 | 不适用 | 不触发 mygo vet |
| native 根包非测试 Go 文件、依赖变动 | 不适用 | 不适用 | Go 验证前运行 mygo vet，失败不记成功 |

树规则（32 DIP 是本任务阈值，不冒充平台强制标准）：

1. 节点越出客户区或最近 scroll 视口的水平方向时报告越界；正常纵向滚动边缘排除。完全移出客户区的控件也检查，不单凭 offscreen 跳过。
2. 文字节点在非滚动边缘被几何裁剪且没有省略标记时，报告待核对的裁字。AX 不提供排版宽高、实际绘制的省略号，不能证明框内字形截断或合法 SingleLine 是否出现省略；报告必须明确这项限制，不写全量通过。
3. 具有 press 动作且未 disabled 的可见命中框任一边小于 32 DIP。
4. 同一父级、同一角色的 tab/radio/list 导航同行兄弟比较高度；图标按钮比较宽高，不把内容决定宽度的文字按钮或不同高度的聊天消息混成同族。
5. 同一父级下重复 Key（保留 JSON 类型），以及检查器 Issues 中的重复 key。AX 省略布局父节点，AX 重复候选须对照 Issues，不能把跨布局父级重复当作已证实冲突。
6. 指定空状态区域及 setSize=0 的 list 无可见说明文本时报告；不把任意无文字装饰容器当空状态。

Issues：每状态截图后打开 F12 → Issues，导出检查器树；关闭后恢复尺寸。检查器是累积警告，不能把各状态相加当独立问题。帧：逐行收 stderr 的 MYGO_FRAME_STATS=all，区分正常状态段与检查器段，记录完整原文和最慢帧 build/layout/paint/present。截图、JSON、命令耗时、文件字节数均写产物；报告不以帧数低、截图好看宣称性能达标。

## 验收

真启动新 e2e 进程，完整跑状态清单；确认截图物理尺寸与实际客户区、比例一致；每状态 PNG/JSON、Issues、帧段与报告可打开。六条规则各用编的树正反样本，随后逐条拆掉规则判定运行失败，再恢复；另用真实窗口缩到 20×20 的测试按钮验证点击目标规则。只跑相关 Go 包、Bun 验证脚本测试及 mygo vet，重活逐命令拿共享锁、经 run-low.ps1。交回列现有问题，不修或压掉诊断；改动暂存、不提交。
