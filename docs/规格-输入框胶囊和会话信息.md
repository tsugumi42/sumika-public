> - 布局试衣间（（私有链接））的输入框方案 2；主人选它，但不要标题栏药丸。

> - [规格-右栏上下文](规格-右栏上下文.md)：右栏“上下文”栏已有的每轮请求数据（`ctlproto.ConvTurnsReport`，每次请求的总输入 token）。

## 一、要解决什么

本地输入框是一张大卡片：空着也有三行高，底下一排模型、工作区、审批方式药丸。主人觉得像把手机比例搬到了电脑上；这几样也不常换，不该每条消息都占着位置。上下文用了多少现在界面上看不到。

## 二、做成什么样

1. **输入框是胶囊**：空着和单行时高 = 内距 × 2 + 发送键，正好是胶囊；打到多行就往上长，圆角不变，自然成了圆角矩形（`chatui.ComposerRadius` 本来就是“内距 + 键半径”）。里面只有文字和右边的发送键（以后加附件钮也在里面）。本地私聊、本地群聊都一样，和别的平台的“交给她”输入框是同一个组件。
2. **头像外圈是上下文环**：聊天标题浮条上的头像外面套一圈细环，按“最近一次请求的输入 token ÷ 这个模型的上下文窗口”画出用了多少。悬停提示写“上下文用了 62%（8.1 万 / 13 万）”；点头像打开右栏的“上下文”栏。读不到数（没有请求过、模型没报窗口）就不画环，不画假的 0%。用量往回掉（压缩了）时环用回弹以外的平滑动画倒退回去；以后后台报“压缩了”的事件时再加专门的动效（第五节第 4 步）。
3. **右栏“上下文”栏顶部是“这个对话”**：一块摘要，从上到下是上下文用量（一条细进度和“8.1 万 / 13 万”）、模型、工作区、审批方式；模型、工作区、审批方式是原来输入框底行的那三颗药丸，点开就是原来的菜单，写入走原来的路径。下面接原有的轮次列表。本地群聊只有审批方式（几个角色各用各的模型）。

## 三、参数

| 项 | 值 | 令牌 / 出处 |
|---|---|---|
| 胶囊最小高 | 控件大档 `size.ctl.lg`（默认 48）：四边内距 `(HLg − ComposerSend) / 2 − 1`（1 是描边）+ 发送键 | `chatui.ComposerMinHeight` |
| 文字左边 | 外框内距 + 左外边距 = `ComposerPad`；单行时整行垂直居中，多行时发送键贴底 | `chatui`（几何检查要每层四边内距同档，所以用外边距不用不对称内距） |
| 头像环线宽 | 2 | `size.hairline × 2`（先写成常量 + 注释，第 4 步进令牌） |
| 环和头像的间隙 | 2 | 同上 |
| 环的颜色 | 已用：角色色 `accent.line`；超过 80%：`danger` 的文字档；底圈：`line` | `design` |
| 环变化动画 | `motion.panel` 230ms，`ease.route`，不回弹 | `design` |
| 窗口 | 先用那次请求自己记下的上限（读轮次时只给最近一次成功的请求读 `context_json` 里这一个数，`ConvRequest.Window`；不自动读整份请求详情）；没有再用模型列表里报了来源的窗口 | `runstats.fillLatestWindow`、`workbench_conv_info.go` |
| 刷新 | 跟右栏上下文同一份数据和同一个刷新节奏（5 秒，只在本地会话、窗口看得见时） | `workbench_side_context.go` |

## 四、禁止的偷懒写法

- 用“这个会话 token 总和”或字数估算代替“最近一次请求的输入”；数不对宁可不画。
- 把三颗药丸复制一份到右栏：要搬，不复制（输入框里不再有）。
- 环用写死的颜色或像素。
- 读不到窗口时用 128K 之类的默认值算百分比。

## 四点五、已知的坑

- `ComposerMinHeight` 原来是三行（`112 × TS`），根包 `workbench_composer_geom_test.go` 钉着“要是大块的”，要一起改。
- 外壳给输入框预留的高度是 `Geometry.ComposerMin + SpacePanel`（`frame.go`），也要跟着改成胶囊高，否则消息列底下空一大块。
- 右栏“上下文”栏只在看得见时读数；头像环要在右栏关着时也有数，所以读数要挪到聊天区层面（同一份状态，不另起一份）。
- 多行时发送键要贴底，不跟着文字居中。

## 五、步骤（每步一个提交）

1. 规格和 ADR-351（本提交）。
2. 输入框胶囊：改最小高、文字留白、去掉本地的底行；外壳预留高度跟着改；测试改成“单行是胶囊、多行长高、圆角不变”。
3. 右栏“上下文”栏顶部摘要：三颗药丸搬过来，加用量条。
4. 头像上下文环：读数挪到聊天区层面；`winshell.HeaderSpec` 加用量；画环、悬停、点击开右栏；读不到不画。压缩专门的动效等后台有事件再做。
