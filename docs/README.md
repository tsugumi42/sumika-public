# 文档索引

每份文档管一件事；同一件事只在一处写全，别处只放链接（ADR-065 第 7 条）。改完一份记得看 [AGENTS.md](../AGENTS.md)「文档分层」里"改什么要同时改哪里"那张表。`bun run check:docs` 会查这份索引有没有漏掉文件。
