# 规格：模型故障切换

> 状态：2026-11-09 定稿，feat/model-failover 已实现，已合 main。
> 参考：Go Agent 框架对照（私有存档）；[读码] Eino `adk/failover_chatmodel.go` 的 `ModelFailoverConfig`、`needFailover`（故障切换包住同模型重试、取消优先、部分输出单独处理），`adk/retry_chatmodel.go` 的 `TypedRetryDecision`（重试和输入改写分开）。只借做法，不引框架或依赖。边界采用[常见边界清单](notes/清单-常见边界情况-2026-10-26.md)中的部分失败、取消、历史一致、预算、缓存与配置空值。

## 路线与参数

- `defaults.fallbackModels: []` 是全局有序备选链；`characters.<id>.fallbackModels` 覆盖，省略或 null 继承，显式 `[]` 禁用。链中只填主人已经测过适合该用途的模型；程序不自动探测、不硬编码模型名。角色的对话与后台岗位共用该链。
- 空链完全沿用原重试、半截输出及错误流程。启用时仍先执行现有同模型重试；本地已经出字的重试禁止规则保留，此时可以直接进入故障切换。
- `llm` 提供共享判定和内存冷却选择器；`turn` 管本地草稿、历史、工具边界，后台调用复用选择器；所有实际请求仍逐次走 `modelcall.Client.Stream` 的同一根预算、容量与 trace 边界，使用不同 AttemptID。
- 仅 `network/timeout/stream_error/rate_limited/server_error/model_unknown/auth` 可换；未知错误不换。明确参数错误、内容拒绝、上下文溢出不换。请求上下文已取消或截止、根预算耗尽、记账或记录失败不换。
- 失败模型按规范引用 `服务商ID/模型ID` 冷却 60 秒（ADR-390 M2：原来按客户端来源内的模型 ID，现在把来源换成服务商 ID，同名模型在两家服务商互不影响）；从同模型重试结束时开始。选择链中第一个未冷却模型，过期重新按原链优先级尝试；重启清零。60 秒覆盖短暂过载和下一步工具往返，同时不永久锁到备选。时钟、冷却时长及重试等待可注入。所有候选仍冷却则直接报错，不偷偷再打故障模型。
- 每一步只重跑尚未成功的模型请求；工具只在模型成功结束后派发，已经完成的前面步骤与工具结果保留。失败尝试的正文、思考、半截工具调用不追加历史；本地累计草稿清空，失败思考标作废，再开始新模型。QQ 私聊、QQ 群不向外发切换说明。
- 切换时剥离旧模型的 reasoning、reasoning_content、reasoning_details / 签名，保留普通消息与工具调用/结果配对；新模型能力重新决定思考档位、系统角色、上下文/输出限制。后续步骤及下一轮不能把新模型签名回放给旧模型。
- trace 每次实际调用保留原模型、前一模型、切换原因类别、实际模型与成功/失败；使用现有 `context_json` 附加 `failover` 元数据，不新增迁移。冷却跳过在下一次调用元数据中记录。本地 `ProcessStep` 给短说明。
- 全链失败列出实际尝试及冷却跳过的模型，保留底层错误链；不会把失败半句当成功答复。

## 禁止与已知坑

不加依赖、不配置真实数据、不打真实模型、不写供应商 key；不绕预算、审批和权限；不重放已经派发的工具；不将所有 4xx 或所有未知流错误当作模型故障。新设置的继承与显式空链必须区分。跨模型剥思考不可破坏原始普通内容、工具 ID、图片。trace 的 turn 补记不能覆盖故障切换元数据。冷却表并发安全；键带服务商 ID，所以不同服务商的同名模型不共享冷却。只有 OnDelta 的消费者不能撤回累计文字；生产桌面使用可清空的 LocalDraft 快照。压缩摘要和子运行仍只做同模型重试，不走备选链；记忆整理和审阅走同一选择器。

## 验收

假 HTTP/SSE 服务与 `t.TempDir()`，不依赖真实网关：

1. 空链行为不变；配置继承、覆盖、显式空链有效。
2. 同模型重试耗尽才换；网络、过载、限流、超时、模型不存在及鉴权失败可换；参数、内容拒绝、上下文错误、停止不换。
3. 半截流失败后本地草稿撤回，历史/持久记录及下一轮请求只有成功模型正文；前面工具只执行一次。
4. 思考签名与字段不跨模型，包括冷却过期切回；工具配对保留。
5. 冷却期跳过，过期重新尝试，全链失败列出模型；每次真实尝试进根账本，预算用完后不再派发。
6. trace 能关联同一步所有尝试、切换原因及结果；本地有过程说明，QQ 两场合没有对外说明。
7. 后台模型调用使用同一策略、冷却和预算；不满足能力的备选不得静默丢弃图像。

验证只跑受影响相关包，前台等待完成；`gofmt -w`、文档检查和提交钩子通过后提交本分支。实际模型质量及真实窗口显示另需真实环境验证，本轮不做真实调用。
