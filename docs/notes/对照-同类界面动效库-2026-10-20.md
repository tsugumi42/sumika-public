# 对照：同类界面动效库盘点（2026-10-20）

## 结论

1. **最值得以后照着做的五个**：① dotUI（动效按"角色"定表，弹簧也是转成 CSS `linear()`，和我们同一条路）；② Intent UI（React Aria + Tailwind，`entering:` / `exiting:` 写法和我们一致，可以逐个组件对照）；③ HeroUI v3（React Aria + 纯 CSS，不依赖 Motion，数值很具体）；④ SmoothUI 里的 `ai-*` 一组（折叠思考、审批、计划清单，是聊天界面独有的场景，只借做法）；⑤ motion-primitives（共享元素变形的对话框 / 弹层，给"液态玻璃"那一种风格用）。
2. **建在 React Aria 上的只有这几家**：Intent UI、Untitled UI React、dotUI、HeroUI v3、React Spectrum S2、Jolly UI（2025-01 后没更新）、Marigold。B 类（Magic UI、React Bits 等）全部是 Radix 或 Base UI 或自己写，**没有一家建在 React Aria 上**，只能借效果和 Motion 写法，不能借组件结构。
3. **只适合看效果、不适合抄**：React Bits（MIT + Commons Clause，GSAP / three / ogl 很重）、Eldora UI（three / ogl 营销页特效）、Aceternity UI（没有公开仓库，条款原文没取到）、Animata（营销页小部件，质量参差）、Kibo UI（不是动效库）、coss ui 整库（AGPL，只有 `apps/ui`、`apps/origin` 两个目录是 MIT）。
4. **许可证提醒**：animate-ui 和 React Bits 都是"MIT + Commons Clause"（不能把组件本身卖掉或再分发，自己用没问题）；其余看过的都是 MIT 或 Apache-2.0。
5. **以后不靠刷到**：固定看四处，地址和命令见第五节。

### 值得看的具体做法

- **dotUI**：`www/src/modules/studio/axes/motion.ts` 把动效按角色定表：`micro`（悬停、按下、选中）、`travel`（开关拇指、滑块指示条）、`layout`（侧栏）、`anchored`（弹层、菜单）、`hint`（提示）、`modal`、`sheet`、`disclosure`、`notification`、`swipe`。三张表各有出处：**standard**（照 shadcn：弹层 100/100ms，对话框 100/100ms，侧边面板进 450 / 出 400ms，提示条 400/400ms）、**smooth**（照 Radix Themes：弹层 160/100ms，对话框 200/100ms，侧边面板 500/500ms，提示出场 0ms）、**expressive**（照 Material 3 Expressive：全用弹簧，退场统一 200ms 加速曲线）。弹簧用 `springProgress` 算出位置，再用 Ramer–Douglas–Peucker 把 101 个采样点删到够用的几个（容差 0.005），输出 `linear(…)`。对话框有 `scale` / `rise` 等几种进场可选。**对照我们**：第九节表里的数值和 smooth 一档最接近；侧边面板（我们 280ms）比两张表的 400 ms 以上短很多；采样点删减值得看一眼我们 `appearance.ts` 的 `springEasing` 输出有多长。
- **Intent UI**：Dialog 进场 300ms `ease-out`、淡入，桌面端 `zoom-in-95`，手机端从底部滑入，退场 `ease-in` 加 `fill-mode-forwards`（`dialog.tsx:58-82`）；Popover 淡入加按放置方向滑 1 个单位（`popover.tsx:41-43`）；折叠面板用 `--disclosure-panel-height` 做高度 transition 200ms（`disclosure-group.tsx:129`）；标签页指示条 200ms 位移（`tabs.tsx:145`）。我们的 Tailwind 本来就在 `ui` 里，这套类名可以直接对照，不用改写。
- **Untitled UI React**：Tooltip 进场 `ease-out` + 缩放 .95 + 按方向滑 2px，退场 `ease-in`；Select 弹层进 150ms / 出 100ms（`components/base/select/popover.tsx:25-27`）；对话框进场 300ms；滑出菜单只写了进场（`slideout-menu.tsx:22,40`，没看到退场类）。**这是它的短板**，别照抄。
- **HeroUI v3**：Modal 容器进场 250ms `ease-out-quad` + 淡入 + 从 105% 缩进来，退场 100ms 缩到 95%；遮罩 150 / 100ms；触发按钮按下 `scale(0.97)`；每处进出场都跟一句 `motion-reduce:animate-none`（`packages/styles/components/modal.css`）。
- **S2 Popover**：淡入加沿放置方向平移 4px，200ms，退场换 `in` 曲线（`@react-spectrum/s2/src/Popover.tsx`）。
- **官方起步样式用 `transition` 写 `[data-entering]`**（`starters/docs/src/Popover.css`：200ms，平移 8px）。这和我们 LESSONS 里"`data-entering` 只存在一帧、过渡会被跳过"那条**看起来相反**。我没去验证官方这样写为什么能出效果（版本不同？还是在 Chrome 里也有同样问题？），先记下，不改我们的规矩。

## 三、排序

**最值得照着做（按顺序）**

1. **dotUI**：唯一把"每类场景用多长、什么曲线、退场多快"按角色列成表，还标了出处（shadcn、Radix Themes、Material 3）；弹簧转 `linear()` 的做法与我们相同，且新主题要的是"一套统一的动效"。可借的是**表的结构和数值**，不是组件。
2. **Intent UI**：底子和我们一样（React Aria + Tailwind），一个组件一个文件，退场、放置方向的写法都在里面，对照成本最低。
3. **HeroUI v3**：纯 CSS、没有 Motion，进出场数值写得很全，还统一带了减少动态效果的处理，符合"启动包里不带 Motion"。注意它是 npm 包，借数值不借代码；许可证两处不一致，真要复制代码前再核对。
4. **SmoothUI 的 `ai-*` 组**：聊天里的折叠思考、审批、计划清单，别的库都没有。只借"什么时候动、动多少"，实现是 Motion，我们用 CSS 关键帧重写。
5. **motion-primitives**：给"液态玻璃"那一种做共享元素变形（卡片长成对话框、按钮长成弹层）。需要 Motion，只能放在按需加载的块里；它的 `disclosure`、`transition-panel` 克制主题也能用。

**备选**：coss ui 的 Sheet / Tabs / 会变形的 Popover（先确认抄的文件在 MIT 目录里）；Magic UI 的 `animated-list`（新消息进场）。

**只看效果、不抄**：React Bits、Eldora UI、Animata、Aceternity UI（理由见结论第 3 条）；Cult UI 可看但没读源码；Jolly UI 已停更；Kibo UI 与动效无关。

## 四、对我们两种风格的对应

- **液态玻璃**：motion-primitives、Magic UI、SmoothUI、Cult UI 的效果可以挑着做，凡是要 Motion 的都放进按需加载的块，不进启动包。
- **克制的新主题**：dotUI 的 `standard` 或 `smooth` 一档、Intent UI、Untitled UI、HeroUI 的数值；外框不动，丰富的东西只放内容块里（折叠思考、审批、计划清单）。
