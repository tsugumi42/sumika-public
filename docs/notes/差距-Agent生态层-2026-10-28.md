# Go 内核之外的 Agent 生态层：现状和顺序（2026-10-28）

> 2026-10-28 主人问"距离能和成熟的 Agent 本体对比过线还差多少；MCP、skill、给 AI 用的文档和教学、内置工具、注册自定义工具、钩子接口等，哪些有设计哪些没有"，主会话对着规格、待办、ADR 和 `native/` 源码盘点。挂在待办"接入 MCP、更多工具调用、网络搜索、skill"那条。第三节的顺序是我提的，主人 2026-10-28 定了（"就这个顺序吧"，ADR-205）。

结论：内核这一层（规格-Go后台 8.2 过线表）离过线不远；过线表只管"内核稳不稳"，不管"功能全不全"。MCP、skill、搜索、子代理、用户配置的钩子这些，在 Go 上大多只有方向、没有规格。生态层能用的底子是内核已有的插件接口：`Registry.OnTool`（注册工具）、`OnContext`（每回合开头只追加参考信息）、`OnSeen`、`OnSettled`、`OnBeforeCompact`（`native/internal/turn/plugin.go`）。

## 三、做的顺序（主人 2026-10-28 定，ADR-205）

先收完过线表（B2 改题重跑、B4 开着记忆、B6、B7），再按下面做；规格可以先写。每一块先出规格（ADR-083 的格式），规格开头写参考了哪几家、借了哪几条。

1. **上下文来源：读项目说明文件 + skill**。都走 `OnContext` 只追加，不碰缓存；skill 只给目录（名字 + 一句描述），用到再读全文。量小、风险低，又是后面几块的底子。
2. **给模型的自带说明书**：做成第一批内置 skill（工具怎么用、审批是怎么回事、Sumika 自己的功能），顺带把工具说明换成中文、写"什么时候用"。有了 skill 就几乎不用另做机制。
3. **MCP**：工具是运行时才知道的，现在 `OnTool` 只收 `policy.Specs` 里登记过的名字，要先定"动态工具的审批类别"（默认每次都问、不能并行）。同时管住白名单、进程生命周期（停插件时连 MCP 子进程一起收）。工具多了再接工具搜索（BM25）。
4. **网络搜索、抓网页**：三层照旧，先 Tavily；带用量上限（ADR-081 第 3 条"还没定"的那部分要一起定）。
5. **子代理**：QQ 前台派后台的那套靠 3、4，放在它们后面；派出去的子代理按派活的人给工具，审批照样走内核。
6. **和主人协作的通道**：问主人的选项卡、拿给主人看、发图给她（要 mygo 界面配合）。
7. **用户配置的钩子、脚本自定义工具**：MCP 已经能覆盖大部分"自己加工具"的需求，等真有用到再做；做之前照 8.1 的格式先比三家。
8. **按轮撤回文件改动**：先看 Codex 和 OpenCode 的快照做法。
9. 不在这条线里、照原来的位置：直连服务商（ADR-044）、斜杠命令（mygo 线）、定时任务和通知中心、第三方插件的权限审核。

依据：1、2 放最前，是因为它们只追加上下文、不加新的执行能力，审批和听众的规则不用动；3～5 都会给她新的执行能力，按"谁在说话 × 哪个渠道"给（ADR-081、规格-Go后台 8.1"听众和权限"），默认收紧。

## 四、五份调研和它们的抽查（2026-10-28）

Sol 读本机源码写了五份，原样落盘：[项目说明文件与 skill](调研-生态层-项目说明文件与skill-2026-10-28.md)、[自带说明书和工具引导](调研-生态层-自带说明书和工具引导-2026-10-28.md)、[MCP 客户端](调研-生态层-MCP客户端-2026-10-28.md)、[抓网页和网络搜索](调研-生态层-抓网页和网络搜索-2026-10-28.md)、[子代理](调研-生态层-子代理-2026-10-28.md)。Codex 的源码是这次浅克隆到 `_external\codex` 的；Claude Code 没有源码，不在这五份里（想经 ChatGPT 查官方文档，ego lite 开任务空间一直没反应，先放着）。

抽查：派 DeepSeek（omp `auto/deepseek-flash`，思考 high，只读）每份挑 20 条带出处的说法回源码看前后 20 行，另挑 3 处"没找到"的说法用 grep 再搜。100 条里对 80、行号偏了几行 17、说过头 3、不对 0；"没找到"类抽的 15 处都属实（限它说的搜索范围）。说过头的三条，用到时以这里为准：

- 子代理：pi 取子代理结果是"从末尾往前找最后一条带文本块的 assistant 消息"，不是"最后一条消息的第一个文本块"（末尾只有工具调用时会跳过）。
- 抓网页：OpenCode 里 webfetch / websearch 默认 allow 的只是 Explore 子代理；一般的兜底是 ask。
- 自带说明书：omp 的 todo 提醒数的是"非出错的会改东西的工具调用"，不是所有调用。
