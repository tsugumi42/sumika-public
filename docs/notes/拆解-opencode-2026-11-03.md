以下七项是本快照的突出结构，不表示已证明其他产品没有；机制为读码，价值判断为推断。

1. **Code Mode 在一次受限程序中组合工具。** 并行、依赖、过滤由程序表达，减少多轮搬运 JSON，常用工具仍可直接调用。代价是子集语法和程序错误恢复，默认资源限制不齐全。出处：`packages/core/src/tool.ts:247`；`packages/core/src/codemode/tool.ts:72`；`packages/codemode/src/codemode.ts:25`。
2. **规则是版本化输入。** canonical hash/blob/delta 区分观察变化和模型接纳变化，unavailable/removed 分开；缓存和恢复用同一事实。代价是 source codec/render/update 与迁移需要一致。出处：`packages/core/src/instructions/index.ts:17`、`:34`、`:144`；`packages/core/src/session/sql.ts:177`。
3. **提前摘要先算后留。** 用热前缀离线准备，到阈值才切，延长长工具链缓存寿命。代价是真实模型费用和失效产物，需要模型/规则/锚点/tail 校验。出处：`packages/core/src/session/compaction.ts:331`、`:396`、`:953`。
4. **durable inbox 与 doorbell 分工。** 接纳/投递可以恢复，doorbell 只负责不漏唤醒；控制项有屏障。代价是编辑、顺序、取消都要定义事务冲突。出处：`packages/core/src/session/inbox.ts:174`、`:561`、`:608`；`packages/core/src/session/run-coordinator.ts:31`。
5. **流、工具、terminal settlement 分离。** 工具随流开始，ID/ordinal 稳定回填，取消后仍写结局。代价是“中断已接纳”与“已停稳”之间有时间差，客户端必须分清。出处：`packages/core/src/session/runner/step.ts:105`、`:145`；`packages/core/src/session/runner/publish-llm-event.ts:91`；`packages/core/src/session/run-coordinator.ts:16`。
6. **恢复承诺有明确边界。** execution claim 和 10 次/轮预算可续跑，同时明确副作用 at-least-once，不拿 snapshot 冒充外部事务。出处：`packages/core/src/session/execution/restart.ts:24`、`:47`；`packages/core/src/snapshot.ts:43`。
7. **同一 core 可 HTTP 服务或进程内 SDK。** Web handler 无端口嵌入，plugin/workspace driver 是宿主注入点。代价是包、协议、作用域复杂，不能直接推广成每个小模块都拆服务。出处：`packages/sdk/src/internal/host.ts:18`、`:29`、`:58`；`packages/core/src/workspace/driver.ts:28`。
