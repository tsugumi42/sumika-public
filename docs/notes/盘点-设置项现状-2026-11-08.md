# Sumika 设置项盘点（只读，未改任何文件）

下面路径都相对于 `仓库根\`。先说三个前提，表格和清单都依赖它们：

- **旧界面**指 `native/` 根包（`sumika.exe` 正式窗口）。正式窗口的设置页走 `realSettingsView`（`native/status.go:95`）：只有外观、模型、插件（链接解析）、数据位置几处能改，其余分类只读显示配置值，没有接上的显示"还没接上"。

## 二、三类清单

### 1. 后台有、界面都没有

- 控制台地址和端口（`config.go:258-259`）
- 同时保留的对话数、闲置释放、重建带几条（`config.go:321-323`）
- 生命周期、工作上限、预算、调度器（`kernel.go`、`kernel_work.go`、`kernel_budget.go`）
- 顾问和校验代理（`kernel_review.go`）
- 自动压缩闲聊 `agent.context.autoCompactChat`（后台有写入口，模型页不列）
- 群聊闸门默认参数 `group.frequency/jitter/mode`（只有 `sumika-ctl gate set` 能调档位，只许 off/dry）
- QQ 主人号 `qq.owner`、私聊自动回复 `qq.reply`、发送权 `qq.goSend`、媒体下载、补录、合并转发、QQ 本机路径（都不在设表）
- 检查点开关 `tools.checkpoints.enabled`
- 链接代理 `linkReader.proxy`
- 子技能、联网、子代理这三块的生态来源（`kernel_ecosystem.go`，全部默认关）
- 项目说明 `projectContext`
- 嵌入的 `enabled`、`model`、路径类键（设表只读了 `embed.backend`）
- 调试日志 `trace.debug`：Go 侧不读，键也没有界面

## 三、真实配置里和示例不同的值（只说键，不抄值）

真实配置 `data/config/sumika.yml` 的段落：console、magpie、dataDir、charactersDir、defaults、embed、memory、trace、agent、qq、tools、backup、characters、vision、linkReader、plugins。和代码默认值不同、值得注意的：

- `embed.backend` 是 go-models（代码默认 legacy）。
- `qq.goSend`、`qq.reply` 是 true（代码默认 false）。
- `linkReader.expand.bilibiliFormat` 是 cover-text；视频下载关着。
- `defaults.backgroundThinking` 是 high（代码默认 low）；`agent.thinking.private/group` 是 medium。
- `memory.write.characters` 只开了一个角色的 remember，后台整理关着。
- `trace.debug` 键存在，但 Go 不读。

## 四、结论要点

- 正式窗口的设置页基本是只读的。能改的只有：外观（写桌面设置文件）、模型（写 yml）、链接解析（写 yml）、数据根目录（重启生效）。托盘的自动接收和开机启动不在设置页。
- 大部分配置只能改 `sumika.yml`，界面看不到，也改不了。
- 新原型的设置页目前只能看，不能落盘，插件页全是假数据。它没有接后台的任何设置接口。

未找到的项：群聊 `speak` 档位的界面入口（`ctl` 的注释说"在界面上亲手改"，但设置页里没找到）；配置里的成人向预设键；备份的"几点""留几份"对应的配置键。
