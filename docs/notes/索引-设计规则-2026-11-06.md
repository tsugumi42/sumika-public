# 设计规则索引

整理日期：2026-11-06。只读整理 Sumika 已有材料；本文不修改仓库、不制定新的设计决定。

统计口径：规则 R001–R100，共 100 条；冲突 C01–C24，共 24 条。用户原话摘录、令牌行、来源条目和先读清单不重复计为规则。

使用顺序：现行用户决定与 ADR-280、281 → 用户标注的产品骨架 → 《设计语言》的通用几何、语义和交互规矩 → 已有外部研究。ADR-280 已取代 ADR-246、ADR-265，修正 ADR-245；Telegram 的结构与数值不再是验收线，“操作习惯照顾 QQ”仍保留。其他来源只作证据或候选取值。复核时仓库已出现《设计规格-照Grokbot》，它区分实测M、静态S、推断I和Sumika候选P；候选和待用户看不等于最终批准。本文按其补充证据订正旧取样，并按ADR-281覆盖其仍写待定的过程/结果边界。冲突中的处理均明确标为“建议”。

MewTypeUI、mygo-m3e 不作为设计参考。《准则》《方案》《调查》等材料提到它们的部分，仅保留可独立成立的任务、几何、状态和返工教训，不导入其主题、组件尺寸或画法。旧 Bun 规则中的 CSS、React 库及检查命令只代表当时Web实现；ADR-266已重开Bun对照线，界面主线仍按ADR-279为Go+mygo。本文引用其设计原则和历史取值，不把旧命令当作当前原生验收入口。

## 一、规则

“用户原话”表示笔记明确记录用户所说内容；“用户标注”表示 P 的画板内容；“项目约定”不自动等于逐字用户发言；外部规则的项目化处理标“建议”。冲突栏中的 C 编号均可在第二节找到。
