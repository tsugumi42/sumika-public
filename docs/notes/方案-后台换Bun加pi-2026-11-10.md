# 方案：后台换成 Bun + pi，mygo 界面留着（2026-11-10，已定：ADR-345）

挂：待办“客户端服务端拆分第 1 步”（ADR-327）和 Bun 对照线（ADR-266）。主人点头后转成 ADR-344，修正 ADR-203、ADR-266、ADR-327。

依据：三份小样本实测（`data/dev/pi-sample/` 下的 `报告.md`、`第二轮-命令解析和审批.md`、`第二轮-QQ渠道和补录.md`）；Bun 和 Go 核心压测（私有存档）；nsh 对 mygo（私有存档）。主人 2026-11-10 的话：“如果完全对着重写，我觉得不需要花你想的那么长时间，单纯是你没有真实时间流逝的体感”“做呗，你总是智者踌躇不前”。

## 一、结论

后台换成 Bun + pi（插件层用 Cordis），界面继续用 mygo，两者之间走现有的 `api.*` 接口，正好做成 ADR-327 说的客户端、服务端分开。nsh 不在这次范围里，界面帧率的目标不受影响。分六批搬，每批 Go 和 Bun 跑同一份测试数据，Go 一直留着当退路，直到最后一批切换完成。

## 二、实测数字

| | 实际耗时 | 对拍 / 测试 | TS 行数 / Go 对应行数 |
|---|---|---|---|
| 本地私聊一轮（pi 循环、工具、最小审批、插话、停止、存库续聊） | 10 分半 | 28 个测试全绿 | 498 / 约 2 万（只做了顺利路径） |
| 命令解析和审批完整规则（含 ask、作用范围） | 17 分半 | Go 对拍 2671 条全过，另写行为测试 21 个 | 1430 / 5496 |
| QQ 渠道和补录（协议、入库去重、补录、发送确认） | 17 分钟 | Go 对拍 6406 条全过，另写场景测试 84 个 | 1595 / 7703 |

运行：Bun 样本启动 154 ms、空闲 32 MB、测试 1.5 秒、改代码到能再跑 99 ms；首字延迟和直连网关一样，pi 没测出开销。Go 这边一次合并 4～9 分钟，大头是测试。

## 三、为什么换

1. **开发循环快一个数量级**：测试秒级、改完 0.1 秒能再跑；Go 的合并队列动辄几分钟，界面测试每帧软件光栅化，换语言后这部分测试也会跟着重写成更轻的。
2. **少写自己造的东西**：智能体循环交给 pi（跟着上游更新，新压缩策略这类直接拿到），插件热加载交给 Cordis，正好接上“她自己写插件”（待办“插件脚本化”）。
3. **代码量**：同样的功能 TS 约为 Go 的三分之一到一半。
4. **重写成本比原来估的低**：Go 这一整套实际只用了 17 天（10-24 建 `native/go.mod` 到今天）；样本每块都是十几分钟出主干。

## 四、换的风险和对策

| 风险 | 对策 |
|---|---|
| 补录覆盖判断写错会悄悄漏消息（规则只在 Go 代码里，没有规格） | 第 0 批先把 Go 补录、协议、回合调度的场景导出成 JSON，两边共用；QQ 那批先只读影子跑（ADR-266 第 2 条），和 Go 收到的逐条比对，一周无差异再接发送 |
| JS 数字超过 2^53 丢精度（消息号） | 样本已用“长整数先转字符串再解析”兜住，入库层统一按字符串存 |
| 本地 ONNX 嵌入和重排（`localmodels`） | 先做成 Go 小进程，Bun 通过本机接口调；以后有合适的 onnxruntime-node 再换 |
| 审批、可见性这类高风险规则漏移 | 照 AGENTS 第 7 条：Go 的 policy、approval 测试整套移植，改坏检查和独立复核照做 |
| 搬家期间新功能停下 | 每批一两天；Go 线只修 bug，新功能直接做在 Bun 上 |
| 数据和回退 | 用同一个数据目录、同一套 SQLite 表结构和迁移号，换回 Go 就是换回 exe |

## 五、分批

0. **共用测试数据**：Go 的回合调度、补录、协议、审批、记忆召回场景导出成 JSON，Go 自己先跑通，作为两边的验收标准。
1. **Bun 后台骨架和接口**：Bun 进程实现 `api.*` 的那约 46 个方法（ADR-327 第 1 步），mygo 界面改连本机接口；同时 Go 后台也走这套接口，界面换后台只是换地址。
2. **本地私聊核心**：回合、模型调用、工具、审批、记忆召回、存储。
3. **记忆写入、整理、本地群聊、悄悄话、目标和定期任务、提醒**。路由和工单（Super-agent 那套，合并 ADR-295）也在这一批：执行者档案用 Markdown 加头部（名字、管什么、工具、模型、effort，再加 Sumika 的授权上限：场合 × 提出人 × 工具类别），格式照 Claude Code 的 `.claude/agents/`（仓库里已有一份，2026-11-10 主人问“固定分工的子代理也是后台模型的一种吧”）；路由交给便宜模型或规则读 description 分派，贵模型只做要动脑的执行；她以后能提议新档案，主人确认后启用。
4. **QQ 渠道**：先只读影子跑，和 Go 逐条比对；通过后接发送和补录，Go 停止接收。
5. **插件**：链接解析、复读、免费接口等改成 Cordis 插件，热加载；开放“她自己写插件”。
6. **切换**：Bun 成为默认后台，Go 后台留一个版本当退路，然后退役。

## 六、要主人定的

3. 搬家期间新功能是否都做在 Bun 上、Go 只修 bug？
