## 决定（已写成 ADR-340，下面是写 ADR 时的底稿）

- **决定**：
  1. 绑定存 local 库的 `local_workspaces`，以会话串为键。不进配置（配置是全局的），不加在 `local_topics` 上（日常 `console:<角色>` 没有行）。
  2. 目录在每轮冻结那一刻取（`turn.Config.WorkspaceFor`），不在提交时塞进 `turn.Input`。输入载荷会落库，排队和重启恢复的输入因此也跟着新目录走，这才是“下一轮生效”。在跑的一轮不受影响：带目录的实例不再问。
  3. 没绑定就用全局默认 `tools.workdir`。“恢复默认”就是删绑定。
  4. 绑定的目录用不了（不存在、不是文件夹、读不了、没响应、联接改了指向）：这一轮不跑，错误带路径；不回退任何目录。全局默认坏了不拦聊天（今天就是这样，拦了会让一个写错的配置停掉所有私聊），药丸标红。
  5. “这个对话都允许”的授权记着是在哪个目录里点的，换了目录不再放行。不用“换目录时清空”：清空管不到换目录前弹出、换目录后才点的卡。
  6. 列表在预览前写项目名，不分组。Codex 也有“合并显示”；会话栏规格（私有存档）还要按角色折叠，再加项目分组就有两个维度。搜索能搜项目名。
  7. 只有主人在界面药丸或 `/cd` 能改目录；模型没有工具能改。本地群聊、QQ 都不能设。
- **依据**：主人审查第 6 件；ADR-206；ADR-269；AGENTS 安全边界。

## 技术路线

```
药丸 / /cd ── api.LocalWorkspaces（DesktopReader）
        ▼
   local_workspaces（local 库）
        ▲
        │  App.workspaceFor（每轮一次，含 CheckDir、联接指向核对）
turn.Config.WorkspaceFor ──► Input.freezeWorkspace ──► Workspace{CWD, Root}（值快照）
        ├─ 工具 exec(cwd)、检查点
        ├─ 审批 Gate.Check(workdir)、Request.Workdir、ConvGrants 按目录
        ├─ 提示词 {{workdir}}、Config.ApprovalRuleFor(cwd)
        ├─ 项目说明 projectcontext（Root），信任仍看 projectContext.trustedRoots
        └─ 子任务继承父回合的 Workspace；读资料审批用 Hub.InvocationWorkspace
```

- 表 `local_workspaces(conversation PK, cwd, root, real_path, updated_at)`。
- 校验：`turn.CheckDir`（绝对、存在、是文件夹、能列出内容；3 秒时限）。写权限不查。输入整理 `normalizeWorkspaceDir`：去引号、`~` 展开、`..` Clean，相对路径、`C:foo`、`oo`、控制字符一律拒绝。
- 发送前预检：`SubmitLocal`、`sendLocalParts` 在斜杠命令之后、落库之前查一次，失败原样回给输入框，草稿不丢，这句话也不进库。冻结时再查一次（排队、自动续轮、重启恢复走这里）。
- 实例：`hub.go` 复用实例时比较 `Workspace`，换目录自然重建。

## 禁止的偷懒写法

- 不许把目录塞进 `turn.Input` 再落库：排队输入会带旧目录。
- 不许绑定读失败、目录坏了就退到全局默认或用户目录。
- 不许留第二份“当前目录”：审批、提示词规则、项目说明状态、资料读取审批都走冻结的 Workspace，别再调 `a.workdir()` 代表当前会话。
- 不许给模型开改目录的工具。
- 不许在界面每帧查文件系统或读库：药丸只在换会话、改完、点开时读一次。
- 不许把路径放进 QQ、本地群的任何投影。

## 已知的坑

- 改目录要重建实例，这个会话的内存工具历史没了（审查 A3 的老问题），和压缩后一样靠记录恢复。
- 一轮还在跑时目录被删，工具由系统报错。`write` 会按路径重建父目录，写的还是那个路径，不算回退。
- 运行中换目录，在跑那一轮的“这个对话”授权同样不再放行，多问一次，方向是安全的。一类授权同时只记一个目录：换回旧目录要重新点一次。
- 冻结失败（排队、自动续轮时目录坏了）只作为这一轮的错误返回，没有写系统行；`feat/coding-surface` 把回合失败原因显示出来以后会看到。
- `/cd` 在输入框改了以后，药丸在下次点开或切会话时才刷新。
- 迁移号：写的时候 main 和各分支都停在 local `0002`；合并前再看一眼，撞号就顺延（LESSONS）。
- 选文件夹用 mygo 的系统对话框，只在真窗口里弹，Tester 里测的是菜单和后续写入。
- 旧界面（`convlist.go`、`localchat.go`）不做入口，只有审批卡带目录。

## 迁移

- 只加一张空表和一个索引，没有数据搬动。`CREATE ... IF NOT EXISTS`，goose 记版本，重跑不会重复（测了）。
- 上线前备份：退出 Sumika，把 `data/go/chat/local.db` 连同 `-wal`、`-shm` 复制一份。设置 · 数据与备份的备份也包含它。
- 回退：`DROP TABLE local_workspaces;` 并把 goose 版本记录里的 3 删掉。丢的只是绑定，会话回到全局默认目录，聊天记录不受影响。
- 只读归档模式打开旧库不跑迁移：读取先查表在不在，没有就当没绑定（测了）。
