# 需求登记

这是用户（项目主人）对项目怎么做、做成什么样的要求和偏好的唯一出处：散在记忆、ADR、待办、规格里的话收到这里，每条有编号、原话、理解、状态和落点。
状态只有四种：`生效`；`被 R-xxx 取代`（保留不删）；`已做完`（一次性要求且已落地）；`等确认`（新旧说不清，末尾“要用户定的”列出）。
新要求怎么登记：先在对话里写“我理解成……”，用户确认后在对应主题末尾加一条；和旧条冲突就把旧条改成“被 R-xxx 取代”，不删、不另开文件；原话找不到就写“原话未存，转述”。
本文件只收对项目怎么做的要求；怎么和用户相处、说话语气的偏好不在这里。引用里的群名已替换为泛称，条目里不写号码、昵称、账号。
