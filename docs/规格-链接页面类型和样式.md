# 规格：链接的网站与页面类型清单、开关、发出去的样式

> 状态：已合 main：feat/link-page（样式和开关）、feat/link-bili（B 站补齐的页面，第九节）。接 [链接解析模板](规格-链接解析模板.md)（ADR-323）、[链接自动展开](规格-链接自动展开.md)。
>
> 用户原话（2026-11-09）：“图片降级（之前说的旋转图）、通配符、插件页面可以看和手动开关哪些网站进行处理以及各个网站支持哪些类型的页面类型（比如B站的个人主页、动态、专栏、直播间、视频等）支持、在群里发出去的最终样式（卡片、图文、混合）”。设计偏好：默认放开，边界简单，失败要查得到；界面靠结构层级，说明常驻最多一行。
>
> 参考：设置页的“站点 → 页面类型 → 状态加开关”两层结构照 [设计语言](设计语言.md) 的设置分组；样式预设沿用上一份规格的 `@预设名` 机制，不新造模板语言。

## 一、清单（一张表）

`native/internal/linktemplate/catalog.go` 的 `catalog` 是唯一一张表：每行一种页面类型（网站 ID、类型 ID、别名、显示名、支持程度、对应的模板站点键、不支持时的原因、编的示例链接）。

支持程度三档：**能展开**（群里发链接自动展开）、**只能取数**（给角色看和预览用，没有发送格式）、**不支持**（还不认这种链接；原因写在表里，拿到真实样本再补）。`linkexpand.Supports`、`linktemplate.SiteKey`、设置页都查这张表。取数分发（`linkreader/fetch.go`）和识别（`recognize*.go`）不读表，`linkexpand/catalog_test.go` 用每行的示例链接把识别结果和表对一遍，并核对“能展开的行都有模板站点、模板站点都被某一行用到”。

加一个站或一种页面：在 catalog 加一行，能展开的再到 `sites.go` 加模板站点。别的分支新接的站只加行，不改函数。

## 二、开关

配置键（都不写就是全开）：

| 键 | 含义 |
|---|---|
| `linkReader.expand.platforms.<网站>.enabled` | 这个网站整站是否自动展开 |
| `linkReader.expand.platforms.<网站>.kinds.<类型>` | 单个页面类型是否自动展开；整站关着时这个无效 |
| `linkReader.expand.platforms.<网站>.imageMode` | 这个网站发图的方式（ADR-333）：`auto` 普通发优先（默认）、`rotate` 直接发转 180° 优先、`forward` 合并转发里转 180° 优先；按阶梯从选定的那一级开始，不成再往后；动图、视频不转；设置页“网站与页面类型”里每个网站一行“发图方式” |

只管“自动展开”，不影响给角色看（`context`）。判定函数 `config.LinkExpand.KindEnabled(platform, kind)`：别名按表对到同一类型，表里没有的类型不由开关管。两处用它：`linkplugin.OnStored`（决定值不值得排队，短链只看网站开关）和 `linkplugin.run`（取到结果、知道真实页面类型后再判一次，关了就跳过）。每次跳过记一行 `link · blocked`（task_runs，Tag“网站或页面类型已关”），所以“为什么没展开”查得到。快照每次从设置读，保存后下一条消息生效，不用重启。校验：网站 ID 和类型 ID 必须在表里，手写错键启动时报出来。

## 三、图被拒后的降级阶梯（原“旋转重发补洞”，2026-11-09 ADR-331 改写，ADR-333 再改）

> 已被[规格-链接发送改版](规格-链接发送改版.md) A2 节改为：原样 → 整段静态图一起转 180° 同容器重发 → 文字版；`imageMode` 的 rotate / forward 从对应那一级起步。实现合 main 前，下面仍是现状。

先前的旋转重发（ADR-323）只转原图再发一次，卡片、缩略图的重发字节还和原来一样。现在改成阶梯，完整规则和“形状 × 入口”表在[规格-链接解析模板](规格-链接解析模板.md)第七节，这里只写与页面样式有关的几点：

- **顺序**（ADR-333）：正常发 → 直接发并把静态图转 180° → 合并转发里把静态图转 180° → 才退文字版（带原因、试过哪几种、原链接）。不转的合并转发已去掉（2026-11-09 实测救不了被卡的图），只留给能力缺失、动图和视频、转图开关关着的情形。协议端明确拒收换形式；没拿到回执（超时、没回包、SnowLuma 的 `delivery was not confirmed`）先等几秒查历史核实：到了算成功、没到算被拒、查不了不换形式不补发。网站可用 `imageMode` 选从哪一级开始。
- **三种样式都一样处理**：卡片样式的整张渲染图、图文混合里的图、文字样式里的封面单发，到发送端都是“一张静态图”，转 180° 时封面随整张图一起转；视频缩略图同理。动图不转，视频没有备份只能退文字。`Preparer` 不再带 `Rotate180`，旋转在发送端对备份做（`linkexpand.Rotate180`）。
- **只处理问题图**：一条里有多张图时拆成单张，谁被拒只处理谁，别的图原样；被连累中止的后续段原样补发。
- **可查**：每一步写 `link · form_degrade`，转 180° 那步另写 `link · rotate_retry`；日志写段号、形式、结果、换下一级的原因，不写正文。总开关 `rotateOnReject` 管两个转 180° 的级别（网站显式选了 `imageMode` 的不看它）。
- **图片体积**：发送前检查单张体积（`linkReader.expand.imageMaxMB`，默认 20，1～20；QQ、SnowLuma 都查不到权威上限，20 是保守值，也是下载端上限）；X 的 `name=orig` 超限或取不到时退 `name=large`；下载失败写明原因（地址失效、要登录、限流、连不上）。
- 回归测试：`linkexpand/rotate_card_test.go`（卡片整张转 180°、封面一起转）、`linkexpand/image_limit_test.go`、`linkplugin/fallback_test.go`、`app/link_reject_test.go`（逐帧断言）。

## 五、样式：卡片、图文、混合

样式不是新模板语言，是“内置预设加合并转发模式”的固定搭配，`linktemplate.Site.Styles()` 给出，每个站点都有：

| 样式 | 写进配置 | 发出去长什么样 |
|---|---|---|
| 按内置默认 | 不写模板、forward 用 auto | 这个站点原来的排法（B 站视频、X 的默认排版 2026-11-09 起改成用户挑定的，见[链接解析模板](规格-链接解析模板.md)“默认排版”：B 站视频默认是图文，不再是卡片） |
| 卡片 | `templates.<站> = @卡片`，forward never | 一张渲染好的卡片图加链接（有视频槽位的再带视频） |
| 图文 | `@图文`，forward never | 封面或图片加文字，一条消息；图超过直发上限时只发前几张、文字末尾标（发出/总数）；没有合并转发形态的站默认进合并转发（规格-链接发送改版 B3、B10） |
| 混合 | 有合并转发的站：forward always；没有的站：`@混合` | 一句简短提示加合并转发；或先发卡片、文字另起一条消息（图超过直发上限时这条进合并转发） |

`$卡片` 槽位所有能展开的站点都有：B 站视频、会员购用专门排法，其余用 `genericCard`（标题或正文开头、作者、日期一行、一两行统计）。选样式走一个设置键 `siteStyle`（`LinkSiteStyle`），一次写模板和 forward 两项；`CurrentStyle` 把现有配置读回样式，手写的模板显示“自定义”，`@封面文字` 认作图文。B 站视频的内置默认和 `@封面文字` 现在是同一份，所以“默认”和“图文”排出来一样，卡片要手选。卡片没有封面的页面（Mastodon 帖子之类）不画封面区，WebP 封面能解码（2026-11-09）。测试：`linkexpand/style_test.go`（每站每样式能出消息、形状对）、`config/links_switch_test.go`。

## 六、设置页（设置 → 插件 → 链接解析 → “网站与页面类型”）

只在新外壳里画，控件都来自 `winshell`（新增 `Kit.DisclosureRow`：可展开的一行，左边整块按钮、右边放开关或徽标）；旧外壳仍走原来的“消息格式”站点下拉，随旧外壳一起退役。

- **第一层：网站列表**，每站一行：箭头、名字、一句摘要（“7 种页面，5 种能展开”）、整站开关。
- **第二层：页面类型**（点开网站）：每种一行，状态徽标（能展开 / 只能取数 / 不支持）加单独开关；不支持和只能取数的也列出来，写明原因，开关不画（整站关着时类型开关变灰，值保留）。B 站列：视频、动态和图文、专栏、直播间、个人主页、会员购、番剧、课程、音频、合集和系列、小店商品，后面跟几行“不支持”（第九节最后列的那几种）。
- **第三层：展开面板**（点开能展开的页面类型，同一时间开一个）：样式分段（默认 / 卡片 / 图文 / 混合）加一句效果说明；合并转发模式、字数阈值、简介截断；最后是折叠的“通配符模板（高级）”，展开后是模板框、错误写在框下面、插入占位符、套用内置预设、示例数据实时预览、保存和恢复默认。
- 常驻说明只有一行（“关掉的网站或页面类型不会自动展开，不影响给她看。”），其余都在折叠里。

设计自查：数量（第 7 条）17 个网站、50 种页面类型全部展开，宽 2048 和宽 700 各画出 353 / 325 个文字节点，两帧 11.9 / 23.2 ms（`TestPlatformPageStress`；第九节补页面后重量：60 种页面类型，393 / 365 个文字节点，两帧 18.9 / 34.2 ms，机器上还开着别的活，没有再拆）；空、错、加载中沿用链接页原有的读取提示；点击目标沿用 winshell 的行高和开关（32 高）；窄窗口走外壳的两层结构。浅色深色截图见交回。测试：`linkplatforms_test.go`（开关、状态、样式、模板编辑、截图、压力）。
