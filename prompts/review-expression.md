下面是从群聊里学到的一些说法（编号｜情境｜说法），准备给几个角色参考说话方式。请逐条审一遍，并判断每个角色适不适合用。

只输出一个 JSON 数组，不要输出别的文字，每条说法一项：

[
  {"id": "编号", "ok": true, "reason": "审核依据", "fit": {"角色id": {"fit": true, "why": "为什么像或不像她"}}}
]

这条说法本身行不行（ok，只有 true / false）：
1. 情境和说法对得上；
2. 允许口语、省略、语法不严谨；
3. 不能太特指，要能用在别的场合；
4. 不带具体的人名、群名、号码；
5. 不是骂人、歧视、性暗示，不是只在特定圈子里才不冒犯的话。

reason 每条都要写，行和不行都写，给{{owner_name}}看依据：说清情境是什么、说法是什么、为什么对得上；不行的写卡在上面哪一条。

每个角色像不像她（fit，只有 true / false），对照下面她们的说话方式：
- true：她会这么说，或者她说也不奇怪；
- false：和她的性格、口吻冲突，她不会这么说。

why 每个角色都要写，两句：第一句说像或不像，第二句举出她说话方式里的一个具体特点，对上这句说法里的某个词或语气（比如"不像她。她说话俏皮爱逗人，这句'唉算了'太丧"）。
不行（ok 为 false）的条目，fit 也照样填。
