# sumika-gallery：组件画廊

开发用的独立小程序，不进 `sumika.exe`。一个窗口：左边按组件族列出，右边是能点、能拖、能打字的舞台。目的是几秒钟内把一个组件大部分状态点一遍，看清风格和反馈，再切到下一个。

画廊里的每个东西都是正式组件：按钮、分段、输入框这些来自 `internal/winshell` 的 `Kit`，聊天气泡和审批卡来自 `internal/chatui`。没有自己画的仿品。

## 构建和启动

在 `native/` 目录下：

```powershell
go build -o sumika-gallery.exe ./cmd/sumika-gallery
.\sumika-gallery.exe
```

也可以直接 `go run ./cmd/sumika-gallery`。字体用本机 `native/fonts/` 里的文渊圆体、表情用 `native/twemoji/`（都不进 git），没有就退回系统字体。

## 窗口里有什么

- **顶栏**（常驻，放不下会换行）：亮色 / 夜间；底色 冷 / 中 / 暖；字号、圆角、疏密三个滑块（范围和默认值就是 `internal/design` 里的常量）；面板材质 液态玻璃 / 磨砂 / 实色；“显示层”开关。改了以后舞台立刻跟着变。顶栏和左边列表自己不跟字号、圆角、疏密变，免得拖滑块时手底下的东西跑掉。
- **左边列表**：顶上是筛选框，打字就筛。点一下或用键盘切换，没有转场动画。
- **舞台**：上面是“状态排”，把这个组件的几种固定状态并排摆出来，每个带小字标签（悬停和按下要自己动手）；下面是“试一试”，真的活实例，点了有可见结果（计数、文字、消息、审批状态会变）。

材质只影响弹出层（下拉面板、菜单），所以要点开下拉才看得出差别。

## 快捷键

| 键 | 作用 |
|---|---|
| J / K | 下一个 / 上一个组件（光标在文字框里时是打字，不切） |
| ↑ / ↓ | 同上；焦点在舞台里（比如刚拖过滑块）时让给控件自己用 |
| 鼠标点列表 | 切换 |
| 点筛选框后打字 | 按族名、名字、简介筛 |

审批卡里：焦点在卡片里时，回车是“允许一次”，Esc 是“拒绝”。

## 显示层

打开顶栏的“显示层”后，舞台里每一块带底色或边框的容器会描一圈细线，嵌得越深换一种颜色（青、蓝、品红、棕……），舞台右上角写“最深 N 层”和每一层对应的颜色。

做法：mygo 没有公开的元素树接口，所以读固定版本（`go.mod` 里的 v0.9.0）的内部字段，写法和 `internal/uitest` 一样，见 `layers.go`。升级 mygo 后字段变了会读不到，这时舞台右上角写“显示层不可用”和原因，其余功能不受影响。

数得到：有底色或四边边框的元素（控件的底、气泡、卡片、审批块、代码块）。数不到：用 `Draw` 自己画出来的东西（开关的轨道和圆钮、滑块、分段控件滑动的那块选中块），它们不是元素，没有框。

## 加一个新条目

1. 在 `native/internal/catalog/` 里新建 `demo_xxx.go`，写一个 `func xxxDemo(c *ui.Context, e Env)`。用 `e.Section` 排“状态排”和“试一试”两节，用 `e.Cells`、`e.Cell` 摆状态格，用 `e.Play`、`e.Line` 摆试一试和结果文字。控件一律调用 `e.Kit`（`winshell.Kit`）的方法或 `chatui` 的渲染函数，尺寸颜色从 `e.Kit.G`、`e.Kit.P`、`e.Kit.T` 取，不写数字和颜色。
2. 控件的键用 `e.Key("名字")`（会加上条目 ID 前缀）：`Kit` 里分段、加减框、下拉按字符串键记状态，键撞了会串。
3. 要跨帧保留的值（计数、输入内容、审批进度）用 `catalog.Local(e, "名字", 初值函数)`，不要放包级变量。
4. 例子里的文字用真实感的样例（真名字、真句子、真文件名），不用“按钮 1”“Item”。人名、群名一律编的，不取真实数据。
5. 在 `native/internal/catalog/register.go` 里加一条 `Add(Entry{ID, Family, Name, Blurb, Demo})`。顺序就是左边列表的顺序，ID 不能重。
6. 跑测试（见下）：新条目会自动被 `TestEveryEntry` 和画廊测试覆盖，要验证“点了会变”的话在 `gallery_test.go` 的 `TestGalleryInteractions` 里加一段。

接不进来的组件（比如需要后台数据的）不要为它改组件本身，先在条目的 `Blurb` 或交回说明里写原因。

## 测试和出图

在 `native/` 目录下（测试一律经全机名额）：

```powershell
bun ../scripts/slot.ts go test ./internal/catalog ./cmd/sumika-gallery -count=1
```

设 `GALLERY_SHOT=<目录>` 会顺手出图：`internal/catalog` 的测试把每个条目亮、暗各存一张到 `<目录>`；画廊的测试把整个窗口（含顶栏和列表，亮、暗、开显示层、点过之后）存到 `<目录>/window/`。路径用 `C:/...` 写法，不要用 `/c/...`。

测试验证的是：每条在亮暗、字号圆角疏密的最小默认最大下能打开；默认窗口里一族放得下不用滚动；试一试里点一下结果文字真的变；J/K、方向键、点列表、筛选能切；改外观开关令牌跟着变。真窗口里的悬停、按下、拖动的手感测试验证不了。
