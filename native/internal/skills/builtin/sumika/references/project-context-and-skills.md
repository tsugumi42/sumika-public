# 项目说明文件与 skill

来源模块由宿主显式装配，默认关闭；没有目录或 `skill` 工具时不能声称已加载。宿主按当前会话签发来源授权并提供读取审批，选目录本身不产生授权；本地群聊、QQ 私聊、QQ 群的新入口仍默认拒绝。读取仍过[审批](approval.md)。

## 项目说明

用户说明根先取 `AGENTS.override.md`，否则 `AGENTS.md`。项目从 worktree 根到工作目录逐层加载；每层基础文件取首个存在的 `AGENTS.override.md`、`AGENTS.md`、`CLAUDE.md`，再叠加首个存在的 `AGENTS.local.md`、`CLAUDE.local.md`。空文件也算选中；不可读不改选低优先级文件。local 是该层补充，更深目录约束其子树，都不能覆盖宿主权限。默认不认 `CONTEXT.md`。

不预扫子树。成功 `read` 后检查到文件父目录，成功 `ls` 后检查到被列目录；`find`、`grep` 不展开命中目录的说明。`write`、`edit` 前核对完整规则；有未接纳的新版，本次不写，先读完再调。截断、超限、import 失败或审批未过会阻塞写入，须恢复来源、精简内容、调整限额或获准后完整加载，不能盲重试。PowerShell 进新目录前先取说明，不能保证任意命令同样受保护。

`@文件` 相对引用文件解析，支持转义空格；行内代码和代码块不展开。只读普通 UTF-8 文件，不下载 URL 或读网络共享。真实目标须留在 worktree 或授权用户说明根内，链接越界也拒绝；用户说明的 `~/` 只能落入授权用户根。去重并防循环。

暂定预算：单源 1 MiB，当前有效规则合计 32 KiB（含用户说明、imports、路径和标记），import 深度 5（根为 0）、最多 64 个文件，读取并发 8。不完整不能登记为整组已读。更新追加完整新版，删除追加撤销；暂时不可读保留旧资料但阻塞相关写入，撤权后不能继续用旧绑定。

## skill 发现与格式

裸名优先级：显式来源按配置顺序 → 可信项目从近到远，每层 `.sumika/skills`、`.agents/skills`、`.claude/skills` → `<数据目录>/config/skills` → 显式启用的用户兼容根 → 内置。兼容根是 `<用户目录>/.agents/skills`、`.claude/skills`，默认不开。只认 `<name>/SKILL.md`，不递归扫附件、不认平铺 Markdown；每来源根最多 2000 个子目录、20,000 个条目。精确来源 ID 区分同名项；`builtin:sumika` 不能被项目同名项替换。

YAML frontmatter 必须有 `name` 和 `description`；名字与包目录规范化后相同。重复键、多文档或类型错误拒绝该项。`disable-model-invocation` 默认 false，true 时不自动列出也不允许模型自主加载；`user-invocable` 默认 true，直接用户点名须由宿主确认。`allowed-tools` 只作兼容元数据；`context`、`agent`、`model`、`hooks` 没有运行效果，未知字段不转成配置。脚本只当文本读，执行另审批。

## 按需读取与续读

初始只给目录。用 `skill({name:"builtin:sumika"})` 读首页；附件用同一工具加 `resource:"references/tools.md"`。搜索用互斥的 `skill({query:"审批"})` 分支。资源只在包根内解析，拒绝绝对路径、`..`、盘符、ADS、UNC、设备路径和链接越界，不隐式解码百分号。

正文 `limit` 按 UTF-8 字节，目录 `limit` 按条目；均须为正。目录每页默认及最多 20 条，初始目录预算 8 KiB，展示描述最多 512 字符。主文与附件每次结果预算 32 KiB（含框架），单文件 1 MiB，当前上下文各版本已读正文累计 128 KiB；重复读取和更新都计入。

用返回的 `cursor` 续读，绑定精确来源、资源、版本和授权；别自造或混用目录、正文游标，别以“下一行”代替。内容或授权变了游标失效，从头核对，不能拼两版。未完页不等于读完；预算耗尽别无限重调。

切换工作区或收紧权限会取消旧绑定在途工作并换实例，不能撤回已送出的模型资料或回滚副作用。相关现象见[排错](troubleshooting.md)。

当前 loader 只扫描宿主传入的来源根，按传入次序决定裸名；来源根的稳定 ID 不取数组下标。项目层级与兼容根的展开由宿主完成，候选目录不参与自动发现。每页正文先预留上下文额度，宿主接纳才转为已用，丢弃才释放；压缩后换 ContextID 重新计量。
