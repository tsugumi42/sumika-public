# 功能

判断能不能做，先看本轮工具和实际运行入口。模块有实现，不表示当前入口已经接通。用法见[工具](tools.md)，场合见[渠道](channels.md)。

## 现在有的

- Go 内核支持模型回合、工具执行和按听众分配工具。文件工具包括读、列目录、搜索、找文件、写入和修改，也能运行 PowerShell；实际使用受审批限制。
- 记忆模块能查要点、查原话，按听众过滤可见范围；具备写入能力的记忆实例能接 `remember`。当前无界面后台装配把记忆库按只读打开，不要承诺它会保存新记忆。
- QQ 渠道能接收消息、按白名单准入、识别身份、经过群聊闸门（只记录档的群只存消息、不进回合，说话档的群生成试运行结果）。当前无界面后台一次连接所选的一个账号；QQ 群说话档和主人的私聊要等发送启用条件齐了才真发，不齐时群按试运行处理、私聊只存不回。
- 审批政策支持 `manual`、`auto`、`yolo` 和同类授权。当前无界面后台没有审批交互入口，收到审批请求会拒绝；不能让用户去找尚未接通的按钮。
- skill、MCP、网络搜索、子任务已有来源模块与宿主装配端口，默认关闭；启用仍须宿主身份、来源信任、消费额度和当次审批。模块存在不表示当前入口已装配。

## 现在没有的

- 没有第三方 WASM 插件运行时、用户远程 hook、skill 脚本自动执行或自动启用候选产物。ADR-238 的 WASM 运行时仍未开放，没有可用 ABI。
- 当前 Go `read` 不支持图片附件读取；声明中提到图片不代表执行器已经能读。
- QQ 回复默认不会真发：`qq.goSend` 开启或拿到发送锁都不等于已经发送，要发送启用条件都齐了才发；私聊自动回复只对主人，`qq.reply` 没开时私聊只存不回。

遇到“配置有了却没生效”，先查当前入口的接线和限制，见[配置](configuration.md)与[排错](troubleshooting.md)。
