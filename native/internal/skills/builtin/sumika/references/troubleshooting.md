# 排错

先说明实际观察到的现象：当前入口、场合、工具是否出现、返回的错误或状态。只问恢复所缺的信息；不要猜本机配置、文件、连接和模型状态，也不要让用户贴密钥或整份私密日志。

| 现象 | 下一步 |
| --- | --- |
| 没有文件或命令工具 | 先查是本地私聊、本地群聊、QQ 私聊还是 QQ 群，再看宿主给的工具；QQ 不提供本地执行能力。见[渠道](channels.md)。 |
| 操作被拒绝 | 看拒绝原因；不要换工具绕行。审批过期或等待中取消表示该调用没执行，当前无界面后台没有审批交互入口。见[审批](approval.md)。 |
| 已停止、超时，但文件似乎变了 | 已开始的操作可能部分执行；先读回目标或核对命令结果，再决定剩下的工作，别直接整步重做。见[审批](approval.md)。 |
| `read`、搜索结果不完整 | 按提示继续：正文用 `offset`，搜索缩范围或调整 `limit`；单行过大不能靠下一行读完。见[工具](tools.md)。 |
| PowerShell 只见输出末尾 | 找返回的完整输出路径，用 `read` 从所需位置读，不先重跑命令。见[工具](tools.md)。 |
| 读图失败 | 当前 Go `read` 不能读图片；说明限制，不声称看过，也不反复重试同一调用。见[功能](features.md)。 |
| 文件找不到、目录不对 | 核对本次参数和工作目录，用 `ls` 或 `find` 查已授权范围；不要把一个路径不存在扩大成“本机没有”。见[工具](tools.md)。 |
| `edit` 找不到原文、命中多处或重叠 | 重新读目标，补唯一上下文，合并重叠修改后再调；别用整份覆盖掩盖定位失败。见[工具](tools.md)。 |
| 搜索报缺少 `rg` 或 `fd` | 当前实现不会自动下载；请用户修复工具安装或 PATH，再试。原错误即使写“could not be downloaded”，也不表示已经尝试下载。见[工具](tools.md)。 |
| 改配置没变化 | 确认配置定位顺序、字段是否认识、是否重启当前后台；不要把未知键被忽略当作已经启用。见[配置](configuration.md)。 |
| QQ 连接起不来 | 看已打码的错误类别，核对所选账号是否配置、协议端 URL 是否提供、令牌引用变量是否有值；不要要求贴令牌。见[配置](configuration.md)。 |
| QQ 群不回复，或 `qq.reply`、`qq.goSend` 开了仍不发 | 发送启用条件不齐时，群聊最多到试运行（只记录档的群连回合都不进）、私聊只存不回；发送锁只是条件之一，不代表解除限制。私聊还要 `qq.reply` 开着、对方是主人才回。白名单外的群不收；先区分未准入、只记录和试运行。见[渠道](channels.md)与[功能](features.md)。 |
| 记忆缺失，或 `remember` 没记上 | 按当前听众查可见范围和工具结果；没有记忆库可能没挂记忆，当前后台即使有库也是只读。别声称已保存。见[渠道](channels.md)与[功能](features.md)。 |
| 项目说明或 skill 没出现 | 正在接入；先看工具和目录是否实际提供，再查宿主工作区绑定、来源启用及读取审批。别靠加未知配置键打开。见[项目说明与 skill](project-context-and-skills.md)。 |
| 写入因项目规则不完整被挡下 | 这是接入约定：按来源诊断恢复依赖、内容预算或审批；有完整新版先接纳再重调，不完整时不能盲重试。见[项目说明与 skill](project-context-and-skills.md)。 |
| skill 续读游标失效或累计预算耗尽 | 这是接入约定：失效后从头核对同一来源与资源，别拼版本；预算错误不能靠改游标或反复分页绕过。见[项目说明与 skill](project-context-and-skills.md)。 |
| MCP 报服务隔离 | 有一次调用发出后没拿到结果，对方可能仍在执行；不要重连、改服务名或重试来绕过，模型也不能自己解除。主人用 `sumika-ctl mcp status` 看是哪几次，核对后用 `sumika-ctl mcp release <服务> --reason "原因" --accept-unknown-risk` 接受风险解除（旧记录保留，不改成成功）；这条命令在任何档位（包括最宽的 yolo）都要主人在审批卡上点一次，只能批这一次；不要替主人执行，也不要建议“始终允许”。本机服务断了会自动重连，次数用完时主人用 `sumika-ctl mcp reconnect <服务>` 再试。 |
| web 报额度不足 | 0 或缺额度禁止新出网；失败派发仍可能收费，不改 provider 或新建任务绕过。 |
| 子任务显示 stopping 或 held | stopping 在等真实执行退出；held 不自动唤醒前台。只在原授权域核对结果，不能直接把原文发到 QQ。 |
