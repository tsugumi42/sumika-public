# ledger

读一份订单 CSV，算每单的应付金额，统计平均值，再列出消费最多的几位客户。金额一律用“分”（整数）。

## 包

- `parse`：把文本变成订单。`ParseAmount` 把“12.5”这样的金额变成分，`ParseDate` 校验日期，`ParseLine` 解析一行，`ParseAll` 解析整个文件。
- `calc`：算钱。折扣、税、每单应付金额、平均值、中位数。
- `rank`：按客户汇总，列出前几名。
- `cmd/ledger`：读 `data/orders.csv`，打印结果。

## 规则

- CSV 每行：`日期,客户,金额,折扣百分比`；空行和 `#` 开头的行跳过；解析不了的行记一次“坏行”。
- 应付金额 = 金额 - 折扣 + 税。折扣向下取整到分；税按万分比（bps）算，四舍五入到分（0.5 进位）。
- 客户名不分大小写、去掉首尾空白后合并。
- 平均值向下取整；没有订单时是 0。

运行：`go run ./cmd/ledger`。
