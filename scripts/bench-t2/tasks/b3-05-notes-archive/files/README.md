# 生活笔记

这是一个编造的笔记仓库，用来练习整理文件。

## 目录约定

- `notes/`：还没整理的笔记，每篇一个 Markdown 文件。
- `archive/<目录名>/`：整理好的笔记。每篇笔记文件头里的“标签”决定放进哪个目录，标签和目录名的对应关系写在 `tags.txt`（每行“标签 目录名”）。文件名不变。
- `index.md`：根目录的总索引，见下面的格式。
- `tools/`：发布脚本。

## 笔记文件头

每篇笔记开头是用 `---` 包起来的文件头，里面有：

- `title:` 标题。
- `标签:` 这篇属于哪个标签。
- `原文件名:` 只有改过名的笔记才有，写的是它以前的文件名。别的笔记里如果还按旧文件名链接过来，链接要改成现在的文件。

## 链接

笔记之间的链接都是相对当前文件的相对路径（例如 `[标题](other.md)`），移动文件以后要保证每个链接仍然能打开。`https://` 开头的外部链接不用管。链接可以带 `#` 小节名，小节名保持不变。

## index.md 的格式

第一行是一级标题“# 笔记索引”。然后按 `tags.txt` 里的顺序，每个标签一个二级标题，例如“## 做饭”，标题下面每篇笔记一行：

    - [标题](archive/cooking/tomato-egg.md)

方括号里是笔记文件头里的 title，括号里是从根目录出发的相对路径。每篇笔记只出现一次，放在它自己标签的标题下面。
