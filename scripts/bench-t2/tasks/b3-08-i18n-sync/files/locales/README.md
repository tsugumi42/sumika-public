# 界面文案

- zh.json 是基准：另外两种语言的键集合和键的顺序都以它为准，zh.json 本身不在这里改。
- en.json、ja.json 缺的键，先填占位“TODO:<zh 原文>”，等翻译回来再替换。
- 占位符（{n}、{name}、{query}）原样保留，不翻译。
- 文件格式：一层 JSON 对象，键是点号分隔的路径，缩进 2 个空格，UTF-8。
- stats.json 记录各语言的完成情况，每次对齐以后更新：
  - total：zh.json 的键数；
  - keys：该语言文件现有的键数；
  - todo：该语言里值以“TODO:”开头的键数（还没翻译的）。
