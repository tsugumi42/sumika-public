# top

统计出现次数最多的词。

```
wordtool top [-n 个数] [-stop 停用词文件] [文件]
```

- 切词：先整体转成小写，再把所有“既不是字母也不是数字”的字符当分隔符（用 unicode.IsLetter、unicode.IsDigit 判断），切出来的非空段就是词。
- 停用词：文件里一行一个词（util.go 的 `loadStopwords` 已经会读，会去掉空行和首尾空白、统一小写）。停用词不参与统计。
  - 不给 `-stop` 时，默认读当前目录下的 `config/stopwords.txt`；这个文件不存在就当作没有停用词，不算错误。
  - 明确给了 `-stop` 而文件读不了，返回错误。
- `-n` 是最多输出几个词，默认 3。小于 1 返回错误，错误信息里要有 `-n`。
- 排序：次数多的在前；次数一样的按词的字典序（升序）。
- 输出：每个词一行，`词 次数`，中间一个空格。词不足 n 个就全部输出；一个词都没有就什么都不输出（不算错误）。

例：输入 `the cat and the dog and the bird`，默认停用词里有 the、and，`top -n 2` 输出
```
bird 1
cat 1
```
（cat、dog、bird 各 1 次，按字典序 bird、cat、dog，取前 2 个。）
