# uniq

合并相邻的重复行。

```
wordtool uniq [-c] [-i] [文件]
```

- 只合并**相邻**的相同行；不相邻的重复行都保留。
- `-i`：比较时不分大小写。合并后输出这一组里的第一行原文。
- `-c`：每行前面加上这一组的行数，格式用 util.go 的 `formatCount(次数, 行)`。
- 空行也是行，照常参与合并。
- 把输入按 `\n` 切成行；末尾的一个换行不产生多余的空行；末尾没有换行也一样处理。空输入什么都不输出。
- 输出的每一行后面都带 `\n`。

例：输入 `a\na\nB\nb\na\n`，`uniq` 输出 `a`、`B`、`b`、`a`；`uniq -i -c` 输出
```
   2 a
   2 B
   1 a
```
